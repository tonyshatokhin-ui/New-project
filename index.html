Если вы попали на эту страницу после двойного щелчка по index.html — ошибок «CORS» здесь уже не должно быть: здесь намеренно нет ES-модулей.

Сама игра грузится через локальный сервер (по http://).

  1. В корне проекта дважды нажмите Open-game.bat (или в терминале выполните npm run dev).
  2. В браузере откройте страницу dev.html того же сайта:
    http://localhost:5173/dev.html

Если Vite уже открыл окно браузера — обычно как раз уже открывает dev.html.

Старый режим «двойной клик по index.html» для браузера с <script type="module"> больше не поддерживается: это ограничение Chrome/Edge для протокола file://, а не ошибка вашего проекта.
